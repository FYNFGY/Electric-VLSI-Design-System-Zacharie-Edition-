## 需求演进小结（供后续会话快速对齐）

1. **端子标记体系**：黄点=未连接端子（元件/标签/悬空端/节点），红点=已连接端子；蓝点方案已被否决（用户要原生渲染）；原生 Wire_Pin 交叉圆盘（3+ 连接、导线同色、随缩放）必须可见
2. **连线交互**：点击黄点起线 → 预览跟随 + 十字虚线 → 再点定线；W 模式（十字光标、点导线分叉、空白临时端子）；DEL 删线；ESC/右键/W 退出；双击必须走原生 GetInfo
3. **自动连接**：拖动/放置/粘贴时端子-导线（拆线+原生 pin）、端子-端子；安全规则（已连接端子/移动导线不参与）；R 键全局连接；拖拽接触绿色十字高亮（多网络同时）
4. **右键菜单**：空白处 Wire(W)/Auto-Connect(R)/Manipulate Exports；悬空端 Create Export
5. **渲染**：5px 导线、半透明线网格（所有窗口、内容在上）、绿色高亮+绿十字、放置/粘贴预览（形状+黄点）
6. **约束**：快捷键仅原理图生效；不与 Electric 原生功能冲突（双击 GetInfo、右键拖线、布局功能）
